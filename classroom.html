Or send the quiz home instead

Every kid takes the 2-minute quiz and gets their own costume idea. Their pick links back here, so you can see what the class chose.

Assumes the classroom has scissors, glue sticks, tape, and markers. A few guides list those basics again below in case you are running low; skip those lines if you are already stocked. Every costume links to a free build guide with the steps, so send the link home with each kid.

How it works. Pick a class size and age group, then choose a shared theme or assign individual costumes by interest. Costumes come from the same 138-idea bank as the main quiz, filtered to kid-appropriate picks. The shopping list adds up every costume's materials and scales them to your class, splitting "one per student" items from shared supplies.
