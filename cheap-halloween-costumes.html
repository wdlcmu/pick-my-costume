The cheapest build on this page: Cereal Crew

If Halloween is closer than you think, here is the whole build, word for word from the costume guide.

The pick: Cereal Crew

Real numbers: 20 min - $2-4 - Easy

You will need:

  1. Solid-color shirt and pants per person, 1 set each (own)
  2. Empty cereal boxes, 1 per person (make: save from home)
  3. Markers or crayons in assorted colors, 1 pack (own)
  4. String, about 4 feet per person (own)
  5. Scissors, 1 pair
  6. Tape, 1 roll
  1. Each person invents a cereal name.
  2. Open the box along the side seam and flatten it BEFORE cutting, a flat box cuts cleanly, a 3D box wobbles.
  3. Cut the front panel off an empty cereal box with the scissors, keeping the panel as large as possible.
  4. Decorate the panel with the markers or crayons. Draw a mascot, add a prize burst, and write the cereal name in big letters.
  5. Tape string to the top corners of each panel with the tape.
  6. Wear the panel over the solid-color shirt like a sandwich board.
  7. Optional pro finish: add a 'prize inside' burst and a fake nutrition joke ('100% daily value of fun') in the corner. Real cereal boxes have fine print; yours should too.
